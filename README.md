# EXA871 - Projeto de Software

### Objetivo   
Implementar Solitaire e JetUML em Java e Python, executar as quatro versões e comparar decisões de projeto com os softwares de referência.   
Implementações disponíveis:   
- Solitaire em Python — solitaire/python/
- Solitaire em Java — solitaire/java/
- JetUML em Python — jetuml/python/
- JetUML em Java — jetuml/java/

### Execução   
Em cada pasta de projeto:   
Python: python main.py   
Java:   javac Main.java   
        java Main
