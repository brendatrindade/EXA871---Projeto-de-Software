# Solitaire Java

Requer JDK 17+. Execute `javac Main.java` e `java Main`; `java Main --smoke` verifica distribuição, compra/desfazer, reinício e serialização. Os botões Save/Open usam serialização Java e preservam o estado e a ordem das pilhas. A interface mostra a legalidade do destino durante o arraste; clique no monte para comprar, e o monte vazio inicia uma nova partida.
